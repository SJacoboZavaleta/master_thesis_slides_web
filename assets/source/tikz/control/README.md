# Control TikZ assets

`state_manager_transition_slides_standalone.tex` is the compact presentation version of the State Manager transition logic.

Final state semantics:

- FLEX: rose / magenta (`#C2185B` family)
- IDLE: neutral grey (`#E5E7EB`)
- EXT: teal (`#007C91` family)

The slide version deliberately presents the state-persistence rule once as a note instead of adding self-loops, reducing clutter while preserving the implemented logic.
