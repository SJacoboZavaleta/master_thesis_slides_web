# Next steps for slide-adapted tables and dense figures

## Priority tables

### 1. Design-engineering requirements
Create a slide table with 4 columns:
- Requirement family
- Design target
- Implemented response
- Relevance / fulfilled

Use subsystem colour bands:
- TU/FU = fitting and mechanics
- ACT = actuation / transmission
- ELEC = electronics / sensing
- CTRL = control / supervision

### 2. Requirement fulfilment / discussion table
Recommended compressed columns:
- Criterion
- Expected behaviour
- Observed evidence
- Assessment

Use `gold` highlighting for the strongest claims that should be repeated orally.

### 3. Other candidates for slide-specific redesign
- extended state/statistics tables
- controller parameter summary
- experimental campaign matrix
- main result comparison matrix
- limitations / next-step table
